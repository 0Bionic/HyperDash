# HyperDash
This is an infinite runner game that is developed in C++ environment and uses sfml. This game uses different oop concepts like abstraction, inheritance, polymorphism and encapsultion. This game is inspired by the classic Sonic the Hedghog game,
the user can adjust the difficulty level, the spawn rates and game speed is the highest in the Hard level and lowest in the easy level. Some features of the game are spikes, coins and enemy that spawn randomly throughout the game. The player can attack by pressing the space bar to fire bullets. The game includes enemies like  walkers and drones. Moreover, the player their is also a system of power-ups, these power ups also spawn throught the game and are of three different types,
Cyan power up is used to give immunity, orange power up is used for rapid fire and green one is used for health. When a player intersects any of these power ups the sprite colour also changes accordingly and serves the desired purpose.
